# Calculator Using React

A Premium Calculator web app built with React and Vite.

**Overview**

This project is a Premium Calculator Application. The visual design and UI components were created using SnapperUI (snapperui.com). All application logic, state management, and integration were implemented and connected by the repository author.

**Features**

- Basic arithmetic: addition, subtraction, multiplication, division
- Clear and backspace functions
- Responsive UI (SnapperUI)

**Built With**

- React
- Vite
- SnapperUI (design)

**Getting Started**

Prerequisites

- Node.js (recommended LTS)

Install

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build

```bash
npm run build
npm run preview
```

**Project Structure**

- `src/App.jsx` — main application component
- `src/components/` — UI components (e.g. `Button.jsx`)
- `index.html`, `vite.config.js`, `package.json`
